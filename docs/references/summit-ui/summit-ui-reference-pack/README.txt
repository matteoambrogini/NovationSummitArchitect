Source-of-truth rule:
- PHOTO: geometry, relative position, scale, spacing, visual grouping.
- VIDEO: display areas, pages, page order, on-screen labels, navigation behavior.
- VERIFIED REPOSITORY CATALOG: parameter identity, ranges, enum values, firmware applicability,
  verification status, and validated mappings.
Do not infer parameter semantics or ranges from photographs.
Do not invent missing display structure.
